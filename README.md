## About the project
ReleaseShield AI is a lightweight DevSecOps control plane for small teams.
It brings the output of open-source security scanners into one place,
removes duplicate findings, routes each finding to the right owner, and
explains issues in plain language. It is designed for teams that cannot
afford heavy enterprise security platforms.
